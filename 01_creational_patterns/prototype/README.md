기존 인스턴스를 프로토타입으로 사용해서(복제해) 새로운 인스턴스를 만든다
시간이 오래걸리는 작업
* 데이터베이스에서 조회해서 인스턴스를 생성하는 경우
* 네트워크를 거쳐서 http 요청을 보내서 가저온 데이터를 기반으로 인스턴스를 생성하는 경우
매번 db,http를 거쳐서 접근한다면 그 인스턴스를 만들때마다 시간이 오래걸리고 리소스를 많이 쓴다
